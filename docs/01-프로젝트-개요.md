# 프로젝트 개요

## 목표
Spring Boot를 사용하여 **일반 로그인**과 **소셜 로그인(OAuth2)** 을 지원하는 인증 시스템을 구현합니다.

## 기술 스택
- **Spring Boot 3.5.7**
- **Java 21**
- **MySQL** (데이터베이스)
- **Spring Security** (인증/인가)
- **JWT** (토큰 기반 인증)
- **OAuth2** (소셜 로그인)
- **JPA/Hibernate** (ORM)
- **Lombok** (보일러플레이트 코드 감소)

## 주요 기능

### 1. 일반 로그인 (이메일/비밀번호)
- 회원가입 (이메일 기반)
- 로그인
- 로그아웃
- JWT Access Token + Refresh Token 발급
- 토큰 갱신

### 2. 소셜 로그인 (OAuth2)
- Google 로그인
- Kakao 로그인
- 소셜 계정 자동 회원가입

- JWT 토큰 발급

### 3. 사용자/관리자 분리
- **사용자 API** (`/api/auth/...`, `/api/user/...`)
  - tb_user 테이블 사용
  - 일반 사용자 권한

- **관리자 API** (`/api/admin/auth/...`, `/api/admin/...`)
  - tb_adminAccount 테이블 사용
  - 관리자 권한
  - 소셜 로그인 미지원 (관리자는 이메일/비밀번호만)

## 인증 방식
- **JWT (JSON Web Token)** 기반
- **Access Token**: 1시간 유효 (짧은 만료시간으로 보안 강화)
- **Refresh Token**: 7일 유효 (DB에 저장하여 관리)
- Stateless 방식으로 서버 확장성 확보

## 보안 요구사항
- 비밀번호는 BCrypt로 해싱하여 저장
- JWT Secret Key는 환경 변수로 관리
- OAuth2 Client Secret은 환경 변수로 관리
- HTTPS 사용 권장 (프로덕션)
- CSRF 방지 (JWT 사용으로 비활성화 가능)

## 데이터베이스
기존 DB 테이블 활용:
- **tb_user**: 일반 사용자 정보
- **tb_adminAccount**: 관리자 계정 정보
- **tb_refresh_token**: Refresh Token 저장 (새로 추가 필요)
